# 啵啵几何工坊 · iOS

微信小程序 `mini-triangle` 的原生 SwiftUI 版本。

## 功能

- 任意三项三角形求解：SSS、SAS、SSA（二解）、AAS/ASA、AAA
- 角度/弧度输入和结果切换
- 按比例绘图、高线、中线、角平分线、内外接圆与三心显示
- 面积、周长、三条高、半周长、内切圆/外接圆半径
- 斜撑、坡度/高差、管道偏移、楼梯、木工斜切场景
- 本地历史、历史回填、场景开关与排序、应用内字体调节
- 图片导出、文字复制与系统分享

## 运行

使用 Xcode 打开 `BoboTriangle.xcodeproj`，选择 `BoboTriangle` scheme 和任意 iOS 17+ 模拟器运行。

## 订阅配置

场景工具由 StoreKit 2 月度订阅解锁，产品 ID 为 `bobo_monthly`。三角形计算器保持免费；未订阅用户可以查看场景工具预览，并从“场景”或“更多”进入独立的“啵啵会员”页面购买或恢复订阅。

- App Store Connect 中的 Apple ID `6809079594` 和订阅群组参考名称 `bobo_vip` 仅用于后台管理，不需要写入客户端代码。
- 提审前应在 App Store Connect 中补齐订阅本地化、价格、审核截图、销售范围，并将首个订阅与新 App 版本一起提交审核。
- App Store Connect 仍需填写一个可公开访问的隐私政策网址；App 内已提供隐私说明，但不能替代后台要求的网址。
- 真机或 TestFlight 测试时使用 Sandbox 测试账户，确认购买、取消、续期、退款、过期和家庭共享后的权益变化。
